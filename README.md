# Entra ID Mastery — Coursework & Practical Labs

This repository contains my hands-on documentation, architectural notes, and practical lab exercises completed throughout the **Entra ID Mastery Course** instructed by Andrew Chanthaphone. 

The goal of this repository is to demonstrate practical proficiency in managing enterprise cloud identity, access control, and security governance using Microsoft Entra ID (formerly Azure Active Directory).

---

## 🛠️ Key Topics Covered & Hands-On Labs

* **Identity Architecture & User Provisioning:** Managing enterprise users, dynamic security groups, and cloud-native vs. hybrid identity models.
* **Authentication & Access Security:** Implementing Conditional Access policies, Multi-Factor Authentication (MFA), and passwordless standards.
* **Privileged Access Management:** Configuring Privileged Identity Management (PIM) for time-bound, approval-based role elevation.
* **Governance & Lifecycle:** Role-Based Access Control (RBAC), Entitlement Management, and Access Reviews for compliance readiness.
* **App Integration & Single Sign-On (SSO):** Registering enterprise applications, configuring SAML/OAuth, and managing app consent permissions.
